四大元素性格速读

十二星座归为火 / 土 / 风 / 水四元素，理解元素能更快看懂一个人的能量底色。

🔥 火象 · 白羊 / 狮子 / 射手

行动力与外放能量强，直来直去，热情来得快。短板是容易三分钟热度、耐心不足，需要先冷却再决定。

🪨 土象 · 金牛 / 处女 / 摩羯

务实、重物质与安全感，靠积累取胜。短板是容易钻牛角尖、抗拒变化，改变需要给他们时间。

🌬 风象 · 双子 / 天秤 / 水瓶

靠思维与沟通驱动，灵活、爱新鲜观点。短板是想得多做得少、显得飘，落地时要有人帮着收口。

🌊 水象 · 巨蟹 / 天蝎 / 双鱼

情绪与直觉敏锐，共情力强。短板是容易内耗、被情绪带着走，需要被稳稳接住而不是讲道理。

行星小词典（科普）

看懂这几个基础概念，再读星象就不懵了。以下为占星学通行定义，纯科普。

太阳星座
你出生时太阳所在的星座，代表核心自我、外在性格与人生主线——大家常说的"你是什么座"通常指它。
月亮星座
出生时月亮所在的星座，代表情绪底色、安全感来源与潜意识反应，决定你"一个人时"的样子。
上升星座
出生那一刻东方地平线升起的星座，代表你给人的第一印象、后天自我面具，常被称为"别人眼里的你"。
守护星
每个星座有守护行星，赋予其能量基调（如火星赋予白羊行动力，金星赋予金牛/天秤审美与和谐感）。
水星逆行（水逆）
水星掌管沟通、交通、合同与电子设备。逆行期易出误会、延误、丢件，宜复盘与收尾，不宜开启重大新事。
日月食
占星中象征"转折的触发器"，常带来关键发现与变化，推动人走向更合适的方向，也为生活开启新的可能。
